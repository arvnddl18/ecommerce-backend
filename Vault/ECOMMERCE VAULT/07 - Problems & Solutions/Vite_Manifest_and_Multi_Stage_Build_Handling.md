# Vite Manifest and Multi-Stage Build Handling

Status: VERIFIED
Last Updated: 2026-09-23
Tags: #problem-solution #vite #docker

## Problem
In production containers, requests crash with:
`Illuminate\Foundation\ViteException: Unable to locate file in Vite manifest: public/build/manifest.json`.

## Root Cause
In local development, Vite runs via a development server on port 5173 with hot-reloading (`public/hot`). In production containers without Node installed, Laravel expects `public/build/manifest.json` generated by `npm run build`. If Vite assets were not pre-built or copied during the Docker build stage, Laravel throws this exception.

## Solution / Prevention
1. **Multi-Stage Dockerfile:** In `docker/php/Dockerfile.prod`, stage 1 executes `npm run build`:
   ```dockerfile
   FROM node:20-alpine AS frontend
   WORKDIR /app
   COPY package*.json ./
   RUN npm ci
   COPY . .
   RUN npm run build
   ```
2. **Copy to Final Stage:**
   ```dockerfile
   COPY --from=frontend /app/public/build /var/www/html/public/build
   ```
3. In local development, ensure `npm run dev` is running, or build once with `npm run build`.
